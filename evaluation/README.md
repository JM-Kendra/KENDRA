# Evaluation

Version-controlled evaluation definitions belong here. Generated runs, results, artifacts, and reports are ignored and must remain reproducible outputs.

The active candidate dataset is `gold_cases.json` (`kendra-bir-public-gold-v2`). It remains `initial_expert_review_required`; see [`cases/M5_GOLD_V2_REVIEW.md`](cases/M5_GOLD_V2_REVIEW.md) for the independent-review and adjudication packet. A mechanical validation pass is not approval.

Preregistration drafts under this directory (e.g. `EXP-11_PREREG_DRAFT.md`) claim an experiment ID. Check [`../docs/EXPERIMENT_REGISTRY.md`](../docs/EXPERIMENT_REGISTRY.md) — the single source of truth for ID allocation — before naming a new one.
